# CASA NOVA | Nico & Clau

Web compartida del piso. Los datos se guardan en Netlify Blobs (incluido en el plan gratis).

## Publicarla
1. github.com → New repository → nombre `casa-nova` → Create.
2. En el repo vacío: "uploading an existing file" → arrastra TODO el contenido de esta carpeta (public, netlify, netlify.toml, package.json) → Commit.
3. app.netlify.com → Add new site → Import an existing project → GitHub → `casa-nova` → Deploy.
4. Comparte el link `https://<nombre>.netlify.app` con Nico.

## Opcional: clave
Site configuration → Environment variables → añade `CASA_KEY` con la clave que queráis → Deploys → Trigger deploy.
